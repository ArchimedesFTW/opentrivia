# OpenTrivia Quiz
<!-- ![Screenshot of a comment on a GitHub issue showing an image, added in the Markdown, of an Octocat smiling and raising a tentacle.](./frontend/src/assets/OpenTriviaQuizLogoSoft.svg) -->
This project is a demo showing a full stack setup to load and ask questions using the [Open Trivia Database](https://opentdb.com/). 

When requesting a question, Open Trivia Database already gives the correct solution as part of its response. That is why a seperate backend was implemented, such that the backend displays the question without already providing the solution. 

The backend is made in Java using the Spring Framework and Swagger. The frontend is made in Vue.js with the Vuetify component framework.

[Try it out here!](https://archimedesftw.github.io/opentrivia-frontend/)
